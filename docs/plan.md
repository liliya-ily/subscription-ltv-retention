# План работ

Цель: оценить LTV и отток подписчиков KKBox и показать, как приоритизировать удержание по связке «риск × ценность».

## Выполнено

Разметка оттока, когорты и удержание, историческая LTV, анализ тарифов и скидок, прогнозная LTV на 24 месяца. Подробности в `PROGRESS.md`.

## Этапы

### 1. Выживаемость (`notebooks/06_survival.ipynb`)
- Кривые Каплана–Мейера по сегментам: тариф, способ оплаты, способ регистрации, наличие профиля.
- Модель Кокса с ковариатами. Расчёт на выборке 10–20% клиентов по хешу `msno`.
- Группа клиентов без профиля в `members` (31% когорты) рассматривается отдельно.
- Сверка с кривой удержания из `02_cohorts` и прогнозом из `05_ltv_forecast`.

### 2. Датасет для модели оттока (`scripts/05_churn_features.py`, DuckDB)
- Признаки из транзакций и профиля: число транзакций, доля автопродлений и отмен, смены тарифа, скидки, средний платёж, стаж, город, пол, возраст, флаг заполненности профиля.
- Признаки строятся только по данным до даты окончания подписки.
- Обучение на `train` (февраль 2017), тест на `train_v2` (март 2017), официальные метки.

### 3. Модель оттока (`notebooks/07_churn_model.ipynb`)
- Бейзлайны: доля оттока по сегменту, логистическая регрессия.
- Градиентный бустинг.
- Метрики: logloss, PR-AUC, калибровка.
- Эксперименты и параметры в MLflow.
- Важность признаков, SHAP.

### 4. Риск × ценность (`notebooks/08_retention_value.ipynb`)
- Ожидаемая потеря выручки = вероятность оттока × прогнозная LTV.
- Кривая «бюджет на удержание — сохранённая выручка» для top-k.
- Сравнение приоритизации по риску, по ценности и по их произведению.
- Эффективность удержания задаётся параметром: причинный эффект по этим данным не оценить.

### 5. Логи прослушивания (опционально)
- Агрегаты по месяцам для 10% клиентов: прослушивания, уникальные треки, доля дослушанных, динамика за 30/60/90 дней до окончания подписки.
- Сравнение качества модели с логами и без них.

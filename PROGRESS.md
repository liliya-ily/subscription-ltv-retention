# Журнал работы

## 20 октября 2026

Начала проект по данным музыкального сервиса с подпиской: хочу разобраться, как клиенты платят, когда уходят и сколько денег приносят.

**Сделано**
- Переписала README.
- Настроила окружение в Docker: добавила DuckDB для работы с большими файлами и 7-Zip для распаковки.

**Что узнала про данные**
- Размеченных клиентов около миллиона: в `train` 992 931 (ушли 6,4%), в `train_v2` 970 960 (ушли 9,0%).
- Транзакции есть у 2,36 млн клиентов, так что для LTV и когорт данных больше, чем для модели оттока.
- Файлы `_v2` дополняют основные, поэтому транзакции берём из обоих.
- Свою разметку оттока можно сделать для месяцев до февраля 2017, март берём из `train_v2`.
- Пол указан примерно у трети клиентов, возраст у большинства записан нулём. Как признаки они почти не годятся.
- Логи прослушивания за март лежат отдельным файлом и не пересекаются с остальными.
